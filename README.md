# Genoflora

Une plante qui pousse en 3D à partir de cellules. Chaque cellule porte le même petit génome ; la
forme de la plante n'est écrite nulle part, elle émerge de la division et des échanges d'hormones.

Voir `docs/Note de faisabilité.md` pour l'idée et les jalons.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File check.ps1
```
